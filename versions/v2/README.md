# VI // LEONIDA — Interactive Cinematic Fan Experience v2

A richer single-page GTA VI fan-concept experience built with plain HTML, CSS and JavaScript. It is intentionally self-contained and works on any static host such as Netlify.

## Run locally
From this folder:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## New interactive systems
- Cinematic boot / loading sequence with skip + remembered intro state
- Dynamic sunset / night mode (`N`) with persistent theme
- Original procedural WebAudio ambience / radio (`R`) — no copyrighted music
- VICE/LINK in-site smartphone (`M`) with Messages, Jobs, Radio, Map, Camera and Settings
- Dynamic wanted / heat system (`H`) with scanner overlay at high heat
- 5-click logo easter egg for max heat
- Random Leonida live events
- Interactive abstract Leonida map with destination state, stats and animated route
- Fictional mission planner with approach, crew, projected heat, cut, time and simulation
- State synchronization between map, mission planner and phone
- Horizontal character deck with profile callouts and 3D pointer tilt
- Cinematic image focus viewer with keyboard arrow navigation
- Magnetic CTA interactions and parallax hero motion
- GTA VI launch countdown
- localStorage for non-sensitive UI preferences only
- Responsive mobile behavior and reduced-motion accessibility support

## Keyboard
- `M` — open / close VICE/LINK phone
- `R` — toggle procedural ambient radio
- `N` — toggle sunset / night mode
- `H` — add one heat level
- `Esc` — close phone / gallery viewer
- `← / →` — navigate gallery while viewer is open
