# VI // Leonida — Cinematic GTA VI Fan Concept

A responsive, single-page cinematic fan concept built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` directly in a modern browser. For best results, serve the folder locally with any static server, e.g. `python -m http.server 8080` and visit `http://localhost:8080`.

## Included interactions
- Scroll progress and parallax hero
- Sticky blur navigation
- Intersection-reveal motion system
- Horizontal character rail
- Interactive Leonida map-style panel
- Cinematic media gallery
- Trailer handoff modal
- Platform + edition selection workflow
- Simulated order review with safe external handoff to Rockstar Store
- Responsive mobile/tablet layouts
- Reduced-motion accessibility support

## Notes
This is an unofficial, non-commercial fan design study. GTA VI / Grand Theft Auto and official imagery belong to Rockstar Games / Take-Two. The site does not collect payment or personal data.
